# CollabSphere Profile

This repo contains the CollabSphere mobile app. It is a focused React Native + Expo build with Supabase auth and realtime chat.

Highlights:

- OLED black interface with terracotta, sage, and ochre accents
- Glassmorphism cards with subtle borders
- Auth flow with Supabase and AsyncStorage persistence
- Realtime chat using Supabase Realtime
